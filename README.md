## Interview Focus

- CI vs CD
- Jenkins Controller vs Agent
- Jenkinsfile / Pipeline as Code
- GitHub Webhooks
- Credentials & Secrets
- Build → Artifact → Deployment
- Docker + Jenkins
- Staging → Production
- Health Checks
- Rollback
- Parallel & Distributed Builds
- Pipeline Optimization
- CI/CD Security
- Kubernetes + Jenkins
- CI/CD Troubleshooting
